#### New step `force-delete`

```ts
{
  id: 'force-delete',
  title: 'Permanently delete a trashed tenant',
  summary:
    'DELETE /api/v1/owner/tenants/{tenant}/force requires a trashed, owned tenant and delegates to TenantPurgeService.',
  actor: 'Owner',
  request: { method: 'DELETE', path: '/api/v1/owner/tenants/{tenant}/force' },
  middleware: ['web', 'auth:owner', 'ResolveSessionRealm'],
  controller: 'TenantController@forceDelete',
  service: 'TenantPurgeService::purge',
  models: ['Tenant', 'TenantPurge'],
  tables: [
    { table: 'tenant_purges', operation: 'insert', detail: 'Audit snapshot before deletion.' },
    { table: 'tenants', operation: 'delete', detail: 'Force delete the tenant row.' },
    // users, posts, subscriptions, billing mirrors, invitations, support rows
  ],
  response: '204 no content',
  errors: ['422 tenant is active', '404 tenant not owned'],
  files: [
    'app/Http/Controllers/Api/Owner/TenantController.php',
    'app/Services/TenantPurgeService.php',
    'app/Models/TenantPurge.php',
    'database/migrations/2026_10_30_000000_create_tenant_purges_table.php',
  ],
  speakerNotes:
    'The audit row is written first because the tenant row will not exist afterwards.',
```
